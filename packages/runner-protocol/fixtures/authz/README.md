# Authorization fixtures

Shared by the Rust and TypeScript sides of the authorization plan
(docs/plans/2026-10-15-authorization.md). Not used by any test yet: the
plan's first work package turns them into required checks (T2, T3).

- `datalog/*.json`: one grant per file (authority block, appended blocks,
  the authorizer, ambient facts per action) and its expected verdict. Both
  implementations must give the same verdict for every file. The keys
  inside are TEST ONLY (sha256 of a fixed label) and sign nothing else.
  Generated by `spikes/2026-10-15-authorization/biscuit-ts/gen-fixtures.ts`.
- `corpus/p4-berth-gate.jsonl`: 87 requests recorded at a protocol-4 gate
  (berth vm) from git, gh, npm, curl and apt in a keel machine, with the
  actions a gate derives from each. Placeholders are fixed, no credential
  is in it. `p4-berth-gate.scenarios.json` holds the commands,
  `p4-berth-gate.expected.json` the reference profile and expected verdicts
  (appendix B of the plan).
